# 功能说明

本文档描述各补丁的动机与行为。所有补丁都以精确字符串替换实现，附带断言。

## 稳定性

### 超时与重试
为所有 `AsyncOpenAI` 客户端补充 `timeout` 与 `max_retries`。默认网络抖动时不再无限等待，失败会较快返回并进入故障切换。

### 并发限制
用一个 `asyncio.Semaphore` 限制同时在跑的模型请求数量。群消息密集时避免把上游 API 打满。

### 模型故障自动切换
主模型调用抛异常时，按配置顺序尝试备用模型（如 opus → kimi）。全部失败才向管理员报错。

### 输出容错解析
模型不一定返回严格 JSON。解析逻辑：先按 JSON 解析 → 失败则去除 ``` 围栏再试 → 仍失败则把原文当作单条消息发送。修复“空回复并私聊管理员报错”。

### 全局发送限速
相邻两条消息至少间隔若干秒，降低因短时间大量发送触发平台风控的概率。

## 行为

### 群活跃度冷启动修复
每个群维护一个随时间衰减的活跃度值。原实现对未激活的群直接返回 0，导致基础概率不生效；补丁改为回退基础概率。

### 主动插话冷却
同一群两次“主动发言”至少间隔 N 秒，避免连续刷屏。

### 按群独立人设
`get_system_prompt(is_group, group_id)` 优先读取该群配置的人设，缺省回退全局人设。

## 信息

### 多引擎搜索兜底
命中关键词时，先调用 360 / 搜狗 / Bing RSS 之一做预搜索，把结果作为上下文交给模型。

### 提示词注入当前时间
把当前时间注入系统提示词，减少“今天/现在”类时间幻觉。

## 表现

### 表情包语义挑选
依据回复的语气，让一个对话模型从表情包库中挑选最贴切的一张；模型不可用时回退关键词匹配。

### 图片识别优化
先把图片下载并转为 base64 再交给模型，避免上游拉取外链失败；单条消息只识别一张图片。
