# 群聊参与行为

## 活跃度模型

每个群有一个活跃度值 `p`，取值 `[0, 1]`：

- 群被 @，或机器人主动参与后，活跃度“续租”到配置的基础概率 `group_chat_probability`；
- 之后随时间衰减，衰减到某个下限前仍然可能参与；
- 未被 @ 的群，在冷启动阶段应当使用基础概率。

原始实现在群未进入状态表时固定返回 `0.0`，于是基础概率不生效：只有被 @ 过一次的群才会“短暂正常”。补丁把冷启动回退为基础概率。

## 触发判定

对一条未 @ 机器人的群消息：

```
若 距上次主动发言 < 冷却时间: 不参与
否则:
    若 random() < 当前活跃度:
        交给模型判定是否参与（YES/NO）
        若 YES: 参与，并刷新冷却与活跃度
```

## 冷却时间

冷却用于避免机器人短时间内连续插话。取值偏大更“安静”，偏小更“活跃”。建议 30～60 秒。

## 调参建议

- 希望更活跃：提高 `group_chat_probability`，降低冷却时间；
- 希望更克制：降低概率，提高冷却时间；
- 对特定群单独设置：写入 `group_probabilities[群号]`。
